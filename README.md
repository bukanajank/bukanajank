## What I've Done (highlights)

| Problem | What I did | Result |
|---|---|---|
| Slow queries and timeouts on a Cassandra table | Redesigned primary and clustering keys around the actual query pattern | Typical query time from 20+ seconds to under 5 seconds |
| Data-sync service failing at least monthly | Added an automated restart scheduler and an independent Python validation layer | No recurring sync failures since |
| Manual, one-by-one connectivity checks across sensors | Built Python monitoring with automated log backup | ~100 sensor feeds monitored automatically |
| Production cluster had to move to a restricted environment | Planned and ran the migration, plus a later version upgrade | 4-node, ~4 TB cluster migrated with minimal downtime |
| Undocumented legacy app on MySQL | Read the source code to map the data flow, then redesigned the schema | Migrated to PostgreSQL with data integrity preserved |
